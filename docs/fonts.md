# 글꼴 / Fonts

Noto Serif CJK KR is the recommended optional serif font for Korean Hanja shapes.
Install it from the [official Noto CJK repository](https://github.com/notofonts/noto-cjk).
Use `font-family: "Noto Serif CJK KR", serif` with `lang="ko"`. A Korean locale helps
select Korean glyph forms where a font supports regional variants.

한국어: 한국 한자 자형을 위해 Noto Serif CJK KR을 권장합니다. 위 공식 배포처에서
설치하고 `lang="ko"`를 지정하세요. 글꼴은 선택 사항이며 확장 프로그램은 내려받지 않습니다.
