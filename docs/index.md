# gukhan · 國漢混用

Hangul → Hanja mixed-script converter. 한글 文章을 國漢文混用體로 바꿔 주는 道具입니다.
Gukhan never guesses: an ambiguous word is flagged and left in Hangul. 모호한 낱말은 추측하지 않고 flag합니다.
